# REMINDLY by Zenchik

Android-проект на Kotlin + Jetpack Compose. Это развиваемая стартовая версия, а не завершённая реализация всего списка требований.

## Реализовано в версии исходников 0.2.0

- Главный экран в чёрно-серебристой теме.
- Создание задачи с названием и подробностями.
- Выбор даты и времени напоминания.
- Локальное хранение задач в Room.
- Планирование Android-уведомлений через AlarmManager.
- Действия в уведомлении: «Выполнено» и «Отложить на 10 мин».
- Отмена запланированного уведомления при выполнении или удалении задачи.
- Восстановление запланированных уведомлений после BOOT_COMPLETED.
- Запрос разрешения на системные уведомления на Android 13+.
- GitHub Actions workflow для удалённой сборки APK без Android Studio на телефоне.

## Что ещё не реализовано

Геозоны и GPS-логика, повторные/эскалирующие уведомления, карта и погода, расширенный редактор, чек-листы, вложения, папки и теги, поиск и фильтры, архив и корзина, резервное копирование/импорт, настройки тем и языков, статистика и привычки, виджеты, PIN/биометрия, жидкометаллическая заставка и логотип. Также требуется полноценное тестирование на физических устройствах и разных версиях Android.

## Сборка APK без компьютера

В репозитории уже добавлен workflow `.github/workflows/android-apk.yml`.

1. Создайте репозиторий GitHub в браузере телефона.
2. Загрузите в него содержимое этого ZIP (не сам ZIP как единственный файл).
3. Откройте вкладку **Actions** репозитория.
4. Выберите **Build REMINDLY APK** и нажмите **Run workflow**.
5. Дождитесь зелёного статуса сборки.
6. Откройте завершённый запуск workflow, найдите раздел **Artifacts** и скачайте `REMINDLY-debug-apk`.
7. Распакуйте архив на телефоне и установите `app-debug.apk`. При необходимости разрешите установку приложений из используемого браузера/файлового менеджера.

Сборка выполняется в GitHub Actions на JDK 17, Gradle 8.11.1 и Android SDK 36. Если сборка завершится ошибкой, откройте лог шага **Build debug APK** — по нему можно исправить конкретную проблему.

## Технические параметры

- applicationId: `com.zenchik.remindly`
- versionName: `0.2.0`
- minSdk: 26 (Android 8.0)
- targetSdk / compileSdk: 36 (Android 16)
- Хранилище: локальная база Room
- Сеть для базовых функций не требуется
